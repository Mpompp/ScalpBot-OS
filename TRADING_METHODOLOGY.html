① Bug yang Diperbaiki

Bug #1 — Double Position (Deal ID vs Position ID)

MT5 mengembalikan Deal ID pada OrderSend(), tetapi posisi live menggunakan Position ID yang berbeda. Bot menambahkan kedua ID ke tracker, menciptakan posisi phantom yang langsung terkena SL oleh spread cost (~26 pips = $0.26).

Fix: Pada mode MT5, fill callback tidak lagi menambah ke tracker secara langsung. Reconciliation loop (500ms) menemukan posisi dengan Position ID yang benar dari MT5, lalu menambahkan dengan SL/TP dari pendingFills map.

⟶ Eliminasi ~50% kerugian dari phantom duplicate trades

Bug #2 — SL Terlalu Ketat untuk Gold

SL minimum sebelumnya $2.00 (200 pips) — Gold bergerak $2-5/menit pada sesi aktif. Spread saja sudah $0.26, sehingga SL terkena dalam hitungan detik oleh noise normal.

Fix: SL minimum dinaikkan ke max(ATR×2.0, $4.00). TP minimum max(SL×2.5, $10.00) untuk menjaga RRR 1:2.5. Floor enforcement di asset_profile.go dan momentum.go.

⟶ Trade bertahan melewati noise awal, memberikan waktu untuk thesis berjalan

Bug #3 — Over-Trading (Cooldown Terlalu Pendek)

90 trade dalam ~8 jam dengan 67% loss rate. Anti-revenge cooldown hanya 90 detik, order spacing 45 detik — terlalu cepat untuk Gold M5 yang membutuhkan struktur candle untuk terbentuk.

Fix: Anti-revenge cooldown dinaikkan ke 300 detik (5 menit = 1 candle M5 penuh). Order spacing ke 90 detik. Ini memaksa bot menunggu setidaknya 1 candle M5 setelah loss sebelum re-entry.

⟶ Estimasi pengurangan jumlah trade dari ~90/hari ke ~15-25/hari

Bug #4 — Symbol Normalization Inkonsisten

Setiap package memiliki fungsi normalizeSymbol() sendiri: tracker.go strip ".m", ".pro", ".r", "c", tapi risk/manager.go hanya strip "c". Akibatnya XAUUSDc dan XAUUSD dihitung sebagai simbol berbeda — meloloskan guard MaxPositionsPerSymbol.

Fix: Satu fungsi kanonik model.NormalizeSymbol() di model/tick.go. Semua package (tracker, risk, portfolio, main) sekarang mendelegasi ke satu sumber.

⟶ MaxPositionsPerSymbol bekerja konsisten apapun suffix broker

GBDT Scorer: Diaktifkan sebagai Gate 4

scorer.go sudah ada di codebase tapi tidak pernah dipanggil di pipeline signal. Sekarang terhubung sebagai Gate 4 di filter.go setelah HMM regime gate dan exhaustion guards:

Gate 1 — Range Bypass → Gate 2 — HMM Regime → Gate 3 — Exhaustion Guards → Gate 4 — GBDT Scorer ✦ NEW
Gate 4 Logic: Minimum scorer confidence 55% untuk entry. Confidence akhir = blend 0.6 × HMM_conf + 0.4 × scorer_conf. Scorer menganalisis 12 fitur microstructure: EMA delta, RSI, body ratio, wick ratios, tick velocity, momentum, directional consistency.

③ Metodologi Trading untuk 70% Winrate

Dengan modal 900 USC (cent account) dan lot 0.01, setiap pip Gold = $0.01. Target 70% winrate memerlukan kombinasi edge selection (hanya trade setup terbaik) dan strict risk management.

A. Prinsip Inti: "Fewer, Better Trades"

  • Quality over quantity. Dari analisis trade_history: 90 trade/hari dengan 67% loss = bleeding by spread. Target: 5–10 trade/hari yang highly selective.
  • Spread cost awareness. Gold spread ≈ $0.26 per trade. Pada 0.01 lot, setiap trade memulai dengan -$0.026 loss. TP minimum harus >10× spread untuk edge yang meaningful.
  • Risk per trade: 0.5% (sudah dikonfigurasi). Pada 900 USC = $4.50 risk/trade. Max daily drawdown 5% = $45 = ~10 consecutive losses sebelum circuit breaker.

D. SL/TP Strategy untuk Gold M5

Mode Balanced (Default): SL = max(ATR × 2.0, $4.00) → ~$4.00-$6.00 TP = max(SL × 2.0, $10.00) → ~$10.00-$15.00 RRR = 1 : 2.0 – 2.5 Contoh pada Gold $2,500: Entry: $2,500.00 SL: $2,496.00 (400 pips, -$0.04 pada 0.01 lot) TP: $2,510.00 (1000 pips, +$0.10 pada 0.01 lot) Breakeven winrate = 1 / (1 + RRR) = 1/3 = 33% Dengan 70% winrate + RRR 2.0 → Expected value per trade: EV = (0.70 × $0.10) - (0.30 × $0.04) = $0.07 - $0.012 = +$0.058

E. Saran Implementasi Tambahan

1. Multi-Timeframe Confluence Filter

Tambahkan validasi bahwa M1, M5, dan M15 trend searah sebelum entry. Ini adalah filter paling efektif untuk menaikkan winrate karena menghilangkan counter-trend entries.

// Pseudo-logic untuk MTF filter: m1Trend = EMA5_M1 > EMA13_M1 → BULLISH m5Trend = EMA5_M5 > EMA13_M5 → BULLISH m15Trend = EMA5_M15 > EMA13_M15 → BULLISH // BUY hanya jika ketiga timeframe BULLISH // SELL hanya jika ketiga timeframe BEARISH // Mixed = NO TRADE

2. Consecutive Loss Circuit

Selain daily drawdown circuit breaker, tambahkan consecutive loss limiter: setelah 3 loss berturut-turut, pause trading selama 30 menit. Ini mencegah spiral loss pada market yang berubah karakter.

3. Partial Close Strategy

Pada 0.01 lot, partial close tidak mungkin (minimum lot 0.01). Sebagai gantinya, gunakan break-even lock agresif: setelah profit +$2.00 (200 pips), pindahkan SL ke entry + $0.15 buffer. Ini mengubah winning trade menjadi "risk-free runner".

4. News Blackout yang Ketat

Gold sangat reaktif terhadap NFP, FOMC, CPI, dan PPI. news/blackout_filter.go sudah ada — pastikan aktif dan menutup trading 30 menit sebelum dan 15 menit sesudah high-impact USD news.

5. Trailing Stop Improvement

Trailing stop saat ini menggunakan fixed ATR multiplier. Untuk Gold scalping, gunakan chandelier-style trailing: trailing distance menyempit seiring profit bertambah, locking in more profit saat trade berjalan baik.

// Adaptive trailing distance: if profitPips < 300: trailDist = ATR × 2.0 // Beri ruang awal if profitPips < 600: trailDist = ATR × 1.5 // Mulai tighten if profitPips >= 600: trailDist = ATR × 1.0 // Lock profit agresif
